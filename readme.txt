IMPORTANT — FIREBASE CONFIGURATION

The Firebase configuration included in this GitHub repository is DEMO/PLACEHOLDER data.

Before running the project, you MUST replace the demo Firebase configuration with your own Firebase configuration.

Firebase configuration must be updated in BOTH files:

1. index.html — User Panel
2. admin.html — Admin Panel

Look for:

const firebaseConfig = {
    ...
};

Replace the demo values with your own Firebase Web App configuration from the Firebase Console.

IMPORTANT:
- Do NOT use the demo Firebase configuration for a production website.
- Make sure your Firebase Realtime Database URL is correct.
- Configure Firebase Authentication and Realtime Database rules according to your project requirements.
- The repository contains placeholder/demo credentials intentionally.
