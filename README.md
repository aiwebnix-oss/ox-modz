## 📱 About

**OX MODZ** *(also searched as OxModz, OXMODZ, ox modz, ox mods)* is a trusted Android APK library built to solve a simple problem: the modded-app space is full of low-quality sites, intrusive ads, and unverified files with zero accountability.

Every app goes through a verification pipeline before it's ever listed:

```
  source signature validation  →  multi-engine malware scan
              ↓                              ↓
  real-device install testing  →  post-publish monitoring
```

No auto-scraping. No shady redirects. No dark patterns.

## 🗂️ Project Structure

```
oxmodz/
├── index.html      → Main store — search, filters, catalog (Firebase-driven)
├── about.html      → Brand story, trust & security pipeline, founder
├── admin.html      → Restricted internal dashboard (access-controlled)
├── favicon.png     → Site icon — used across meta/OG tags
├── owner.webp      → Founder portrait, used on the About page
├── robots.txt      → Search-engine crawl rules
├── sitemap.xml     → XML sitemap for search-engine indexing
└── README.md       → You are here
```

> 🔒 `admin.html` is a restricted internal tool — not linked from public navigation, and its internals are intentionally not documented here.

## 🛠️ Tech Stack

<div align="center">

| Layer | Stack |
|:---|:---|
| **Frontend** | HTML5 · CSS3 · Vanilla JavaScript |
| **Backend / Data** | Google Firebase (Realtime Database) |
| **Hosting** | InfinityFree + custom subdomain architecture |
| **SEO** | `schema.org` JSON-LD · Open Graph · Twitter Cards · canonical URLs · `robots.txt` + `sitemap.xml` |

</div>

The store front dynamically pulls the app catalog and site settings from Firebase — search, category filtering, grid/list view, and pagination are all handled client-side for a fast, app-store-like experience.
